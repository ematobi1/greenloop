# GreenLoop web

Next.js 16 (App Router) + TypeScript. The single user-facing app for chat, memory, approvals, agents, workflows, audit and settings.

Every section is a placeholder until its roadmap phase (see `src/app/sections.ts`). The app talks only to the orchestrator API, never directly to the broker or tools.

## Commands

Run from `apps/web` with Node 22.18 or newer:

```powershell
npm install
npm run dev        # http://localhost:3000
npm test           # node:test, no extra dependencies
npm run lint
npm run typecheck
npm run build
```

`AGENTS.md` and `CLAUDE.md` in this folder are generated by Next.js and point coding agents at the version-matched docs in `node_modules/next/dist/docs/`.
